# EduPolicy AI

## Intelligent Document Question Answering System

EduPolicy AI is an intelligent document question answering system that allows users to upload PDF and DOCX documents, ask questions, and get answers based only on the uploaded documents.

## Features

- PDF document support
- DOCX document support
- Text extraction and cleaning
- Document chunking
- Sentence Transformer embeddings
- ChromaDB vector database
- Similarity search
- Question answering
- Source/document reference
- Page reference for PDF files
- Hallucination control
- Chat history
- Multiple document search

## Technologies Used

- Python
- Google Colab
- Sentence Transformers
- ChromaDB
- LangChain
- PyPDF
- Python-docx
- Streamlit

## Project Objective

The main objective of EduPolicy AI is to provide an intelligent document assistant that can retrieve relevant information from uploaded documents and provide reliable answers with source references.
